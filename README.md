# Krypton Updater

The Windows installer and updater for [Krypton](https://krypton.run), a browser
built around your tabs, workspaces, and a calmer browsing experience.

Install with the small web installer, or choose the offline installer when you
need the complete download. Krypton verifies its updates before installing them
and uses smaller delta downloads when available. Your browser profile stays
with you when you update or uninstall.

[Download Krypton for Windows](https://github.com/perpetus/krypton-windows/releases/latest)

This repository contains the installer, updater, and uninstaller source.
Browser source lives in [Krypton](https://github.com/perpetus/Krypton), and its
native interface lives in [KryptonUI](https://github.com/perpetus/KryptonUI).
